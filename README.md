## Compilation + Exécution  
La commande `make` compile le jeu.  
La commande `make run` compile et lance le jeu.
La commande `make clean` nettoie le répertoire build.  

## Menu   
Le menu se navigue à l'aide la souris.  
Clique gauche pour sélectionner le niveau.  

## Contrôles  
On se déplace à l'aide de Z,Q,S,D ou W,A,S,D et les flèches.  
Direction:  
- Z, W et flèche haut pour aller vers le haut.  
- Q, A et flèche gauche pour aller vers la gauche.  
- S et flèche bas pour aller vers le bas.  
- D et flèche droite pour aller vers la droite.  
- Echap pour quitter le niveau.  
- Entrée pour reset le niveau.

Fonctionnalités:  
- R permet d'annuler le mouvement.  
- T permet de refaire le mouvement.  
- CTRL + une direction pour PULL.  

## Mécaniques:  
Implémentation:  
- Les règles de bases NOUN IS NOUN/PROPERTY.  
- Les règles PUSH, PULL, WIN, STOP, SHUT, OPEN.  
- Les combinaisons avec AND.  
- Le undo et redo.
